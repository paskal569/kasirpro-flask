# kasirpro-flask
Aplikasi kasir berbasis Flask dengan fitur transaksi, stok, laporan, backup, dan integrasi printer.
"Sistem mengelola:
→ Multi-user dengan role admin & kasir
→ Ratusan produk dengan kategori
→ Ribuan transaksi
→ Laporan harian/bulanan
→ Export data ke CSV
KasirPro — Point of Sale System
Python Flask | SQLite | Bootstrap

Membangun sistem kasir web full-stack
dari nol untuk membantu UMKM Indonesia
beralih dari pencatatan manual ke digital.

Fitur: Dashboard real-time, manajemen
stok, laporan keuangan, backup data,
integrasi printer kasir.

Impact: Sistem ini bisa menghemat
2-3 jam/hari pencatatan manual
untuk pemilik warung/toko kecil.
